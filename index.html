GitHub bağlantısı

Denemeler GitHub'daki gizli bir depoda tutulur, böylece tüm cihazlarında aynı verileri görürsün. Her cihazda bir kez token girmen yeterli.

Token nasıl alınır?
  1. GitHub → Fine-grained token oluştur sayfasını aç.
  2. Bir ad ver, süreyi istediğin kadar uzun seç.
  3. Repository access → Only select repositories → veri deposunu seç.
  4. Permissions → Contents → Read and write.
  5. Oluştur, çıkan token'ı kopyalayıp buraya yapıştır.
